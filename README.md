# gato.red

**Mi garaje creativo.**  
Proyectos raros, herramientas útiles, juegos absurdos y universos de rol hechos con ganas.

[Visita la web →](https://www.gato.red)

## ¿Qué es esto?

gato.red es mi rincón personal en internet. Aquí suelto todo lo que se me ocurre: juegos, simuladores, herramientas que resuelven problemas reales y sistemas de rol completos. 

Sin frameworks pesados, sin bullshit corporativo. Solo código que funciona, diseño limpio y proyectos que me divierten o que me solucionan la vida.
